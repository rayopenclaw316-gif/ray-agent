## 2. 一句話總結

以 7 通道臉部 sEMG + 5 狀態 HMM 在同 session 內達到 97.3% 詞準確率，但電極重新定位後（跨 session）無補償準確率驟降至 76.2%，透過方差正規化可部分恢復至 87.1%；同時首次定量確認有聲與無聲語音的 EMG 模式存在顯著差異。

---

## 3. 三個主要貢獻

| # | 貢獻 |
|---|------|
| 1 | 首次定量分析電極重定位（session 間偏移最大 5 mm）導致的性能衰退：無補償跨 session 準確率 76.2% vs 同 session 97.3% |
| 2 | 比較 9 種 session 適應方法（VN、FSA、SC 等），最佳（SC+VN）可恢復至 87.1% |
| 3 | 實驗確認有聲 vs 無聲語音的 EMG 模式顯著不同（跨模式識別率僅 73.8%–76.3%），但混合訓練可同時支援兩種模式 |

## 4. 背景與動機

**問題定位：** Chan et al. (2001) 已驗證臉部 sEMG 可用於語音辨識，但所有現有系統只在「匹配條件」（same session，相同電極位置）下測試。

**Session 依賴性來源：**
1. 電極位置偏移（實驗顯示跨 session 偏移可達 5 mm）
2. 環境溫度變化影響皮膚阻抗
3. 電極膏用量不一致
4. 說話者跨天的發音風格變化

**石膏面具（gypsum mask）輔助定位：** 製作每位受試者的石膏面具，孔洞標記電極位置，比貼帶法稍有改善但仍有偏移。

---

## 5. 資料集

**受試者：**
- S1：女，德語母語者
- S2：男，匈牙利語母語者（有大量非有聲語音說話經驗）
- S3：男，德語母語者

**錄製設計：**
- 每人 5 次 session（4 天，早晚各一次）
- 4 次無聲 session + 1 次有聲 session（與無聲 session 同一電極位置同日錄製）
- 每 session：每詞 40 個樣本 + 40 個靜默樣本，詞彙隨機化
- 分割：受試者自控 push-to-talk 按鈕

**電極設備：**
- 7 對 Ag/Ag-Cl 電極
- 參考電極：左手腕自黏按鈕電極
- 記錄系統：Varioport（Becker-Meditec）
- 採樣率：600 Hz
- 濾波：300 Hz 低通 + 1 Hz 高通（無 50 Hz 陷波，保留所有訊號資訊）
- 差動放大

**電極位置（7 通道）：**

| 通道 | 衍生方式 | 目標肌肉 |
|------|---------|---------|
| EMG1 | 單極（參考：鼻） | 二腹肌前腹、舌 |
| EMG2 | 雙極（2 cm 間距） | 提口角肌、顴大肌 |
| EMG3 | 單極（參考：雙耳） | 提口角肌、顴大肌 |
| EMG4 | 單極（參考：雙耳） | 頸闊肌 |
| EMG5 | 單極（參考：雙耳） | 頸闊肌、降口角肌 |
| EMG6 | 雙極（2 cm 間距） | 舌 |
| EMG7 | 雙極（2 cm 間距） | 舌 |

**詞彙：** 10 詞，"zero" 到 "nine"

## 6. 模型架構

### 特徵提取（STFT 差分特徵）

```
7ch sEMG (600 Hz)
    |
    v
[每通道：54 ms 觀察窗，4 ms 重疊]
    |
    v
[STFT → 17 個 delta 係數 + 1 個時域均值 = 18 維/通道]
    |
    v
[7 通道拼接 → 126 維特徵向量]
```

**比較過的特徵集：** 普通 STFT 係數、倒譜、LPC、RMS → 均不優於 STFT delta 特徵。

### HMM 分類器

```
126 維特徵向量
    |
    v
[每詞：5 狀態左右式 HMM]
12 個高斯/狀態
EM 訓練，4 次迭代
    |
    v
[Viterbi 解碼]
工具：Janus Recognition Toolkit (JRTk)
```

## 7. Session 適應方法（共 9 種）

| 方法 | 說明 | 跨 session 準確率（平均）|
|------|------|----------------------|
| BASE（無補償） | 直接跨 session 測試 | 76.2% |
| SC（Session Combination） | 訓練資料跨 session 合併 | 84.1% |
| SS（Session Selection） | 每 session 各訓練一個模型，選 Viterbi 分數最高者 | 83.7% |
| **SC+VN（方差正規化）** | **特徵向量方差正規化 + SC** | **87.1%（最佳）** |
| SC+VN_enr | 用 enrollment 資料計算 VN 向量 | 84.7% |
| SC+FSA_sup（有監督 FSA） | 特徵空間自適應（最大似然轉換） | 未列（適用於單通道） |
| SC+VN+FSA（組合） | 正規化後再自適應 | 52.5%（單通道最佳） |

## 8. 實驗結果

### 同 session（within-session），7 通道，無聲語音

| 通道組合 | S1 | S2 | S3 | 平均 |
|---------|-----|-----|-----|------|
| 最佳單通道 (EMG1) | 74.2 | 92.1 | 77.4 | **81.2%** |
| 最佳 2 通道 (EMG1,3) | 93.5 | 97.6 | 90.1 | **93.7%** |
| 最佳 3 通道 (EMG1,3,6) | 97.1 | 98.1 | 91.3 | **95.5%** |
| 最佳 5 通道 (EMG1,2,3,4,6) | 97.3 | 98.6 | 95.5 | **97.1%** |
| 全 7 通道 | 97.2 | 98.8 | 96.0 | **97.3%** |

→ 2 通道比 1 通道顯著提升（p < 0.01）；**5 通道以上無顯著差異**

### 跨 session（across-sessions），全 7 通道

| 方法 | 平均準確率 |
|------|----------|
| BASE（無補償） | 76.2% |
| SC | 84.1% |
| SC+VN | **87.1%** |

### 有聲 vs 無聲語音比較，全 7 通道

| 條件 | 平均準確率 |
|------|----------|
| 無聲語音（匹配） | 96.8% |
| 有聲語音（匹配） | 98.1% |
| 有聲訓練 → 無聲測試（不匹配） | 73.8% |
| 無聲訓練 → 有聲測試（不匹配） | 76.3% |
| 混合訓練（24 Gaussians） | 96.0% |

## 9. 論文限制

- 僅 3 名受試者，樣本量極小
- 孤立詞，非連續語音
- 詞彙僅 10 詞
- 最佳跨 session 準確率仍只有 87.1%（距 97.3% 相差超過 10%）
- FSA 方法在 7 通道（126 維）時有數值不穩定問題，需降維
- 採樣率 600 Hz 相對較低
- 電極位置仍依賴石膏面具，使用不便

## 10. 與我的研究的關聯

| 面向 | Maier-Hein (2005) | 我的研究方向 |
|------|------------------|-------------|
| 語言 | 英語 | 台灣注音符號 |
| 通道數 | 7（最佳 5） | 4 |
| 採樣率 | 600 Hz | 待確認 |
| 說話模式 | 無聲語音（主要） | 無聲語音 |
| 模型 | 詞級 HMM（5 狀態，12 Gaussian） | CNN + Transformer + CTC |
| 同 session WA | 97.3% | 目標待定 |

**對我的啟示：**
1. **2–5 通道是最佳甜蜜點**：超過 5 通道無顯著改善，4 通道設計合理
2. **跨 session 問題是核心挑戰**：即使用石膏面具輔助定位，偏移達 5 mm 仍造成 21% 性能下降，你論文在設計電極固定機制時需特別注意
3. **有聲/無聲差異量化**：跨模式準確率 73.8%，與 Schultz (2010) 的雙唇音觀察相互印證，共同說明無聲語音不能直接套用有聲訓練模型
4. **混合訓練可行**：如果你的資料集需要同時支援有聲 + 無聲，本文證明增加 Gaussian 數（24 vs 12）可改善混合系統
5. **本文在你論文的位置**：是第二段「傳統方法局限」的核心引用之一，直接點明電極重定位問題

## 11. 五個核心問題

| 問題 | 答案 |
|------|------|
| 研究問題是什麼？ | 如何克服 sEMG 語音辨識中電極重定位（session 變換）導致的性能衰退？ |
| 方法是什麼？ | STFT delta 特徵 + 5 狀態 HMM（12 Gaussian），9 種 session 正規化/自適應方法比較 |
| 資料如何取得？ | 3 名受試者，5 session，無聲 + 有聲語音，10 詞英語數字 |
| 主要結果？ | 同 session 97.3%，跨 session 無補償 76.2%，最佳補償（SC+VN）87.1% |
| 主要限制？ | 3 名受試者、孤立詞、10 詞詞彙、跨 session 恢復仍不完全 |
