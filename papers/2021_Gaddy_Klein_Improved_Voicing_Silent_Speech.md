# An Improved Model for Voicing Silent Speech

- **期刊／會議**：ACL 2021（Proceedings of the 59th Annual Meeting of the ACL）
- **arXiv**：2106.01933v2（2021-06-21）
- **作者**：David Gaddy, Dan Klein
- **機構**：University of California, Berkeley
- **PDF 路徑**：`/Users/rayopenclaw/Downloads/第一章期刊/第五段/An Improved Model for Voicing Silent Speech.pdf`

---

## 1. 一句話總結

以 CNN 殘差塊 + Transformer（相對位置編碼）取代 LSTM，並引入音素輔助損失，將英語 sEMG 無聲語音合成的 WER 從 68.0% 降至 42.2%，改善幅度 25.8%。

---

## 2. 三個主要貢獻

| # | 貢獻 | 說明 |
|---|------|------|
| 1 | 直接從原始 sEMG 學習特徵 | 以 CNN 殘差塊取代手工設計特徵，讓模型自行學習最有利的時頻表示 |
| 2 | CNN + Transformer 架構 | 以 Transformer（相對位置編碼）取代 LSTM，捕捉更長時序依賴，推理更穩定 |
| 3 | 音素輔助損失 | 在 Transformer 上加音素分類頭，提供額外訓練訊號；訓練後丟棄，不影響推理流程 |

---

## 3. 背景與動機

**問題**：EMG-based voicing of silent speech（sEMG → 語音合成）在 open vocabulary 設定下 WER 仍高達 68%（Gaddy & Klein, 2020）。

**現有方法的三個不足**：
1. 手工特徵（小波、頻譜帶功率等）可能丟失原始訊號中的有用資訊
2. LSTM 對長距離時序依賴的建模能力有限
3. 訓練資料量少，模型容易過擬合，缺乏輔助學習訊號

**本研究切入點**：同時改善輸入表示、架構、訓練訊號三個層面。

## 4. 資料集

### 設備與電極配置

| 項目 | 內容 |
|------|------|
| 電極數 | 8 通道（臉部周圍） |
| 採樣率 | 1000 Hz → 重採樣至 800 Hz |
| 設備 | Gaddy & Klein (2020) 相同硬體 |
| 說話者 | 1 位英語母語者（單說話者） |
| 資料量 | 19 小時（無聲 + 有聲雙模式） |

### 前處理步驟

1. 60 Hz 諧波帶阻濾波（去除交流電雜訊）
2. 2 Hz 高通濾波（去除 DC 漂移）
3. 重採樣 1000 Hz → 800 Hz
4. 振幅縮小 10 倍（量值正規化）

### 訓練對齊

- 無聲 EMG 與對應有聲錄音非同步錄製，需動態時間規整（DTW）自動對齊
- 有聲 EMG 與音頻同步錄製，直接計算損失

---

## 5. 模型架構

```
8 通道 sEMG（800 Hz）
        |
  [殘差卷積塊 × 3]      每塊降採樣 ×2，最終 800 Hz → 100 Hz
  通道維度 768          主路徑：BN + ReLU → 1D Conv(3) → BN + ReLU → 1D Conv(3,stride=2)
  捷徑路徑：1D Conv(1,stride=2)
        |
  [Session 嵌入]        32 維 → 線性投影至 768 維，加到每個時間步
        |
  [Transformer × 6]     8 頭，維度 768，FF 3072，dropout 0.1
                        相對位置編碼（k=100，雙向各看 1 秒）
        |
  [線性投影 → 26 維]    輸出 26 維 MFCC（100 Hz）
        |
  [WaveNet 聲碼器]      合成 16 kHz 語音（Gaddy & Klein 2020 不變）
```

### 音素輔助分類頭（訓練時使用）

```
Transformer 最後層輸出
        |
  [線性層 + Softmax]    預測每幀音素分佈
```

損失函數（訓練時）：

```
delta'[i,j] = ||A_V[i] - A_S_hat[j]||_2  -  lambda * P_V[i]^T * log(P_S_hat[j])

其中 lambda = 0.1
A_V[i] = 有聲錄音第 i 幀的 MFCC 目標
A_S_hat[j] = 靜音 EMG 第 j 幀的 MFCC 預測
P_V[i] = 目標音素的 one-hot 向量
P_S_hat[j] = 模型預測音素分佈
```

最終損失 = DTW 對齊後的 MFCC 均方距離 + 音素負對數似然（訓練後音素頭丟棄）

### Session 嵌入設計目的

每次重新貼電極的位置略有差異。Session 嵌入讓模型學習跨 session 的電極位置補償，等同一個軟性的跨 session 適應機制。

## 6. 資料增強

| 方法 | 說明 |
|------|------|
| 批次拼接切片（Batch Concatenation Slicing） | 將一批不等長序列在時間軸拼接成固定長度後分批，隨機切點等同隨機遮蔽上下文，有 dropout 正則化效果 |
| 雙模式訓練（有聲 + 無聲） | 同時訓練有聲 EMG（不需 DTW 對齊）與無聲 EMG，增加有效訓練量 |

## 7. 實驗結果

### 主要結果（Open Vocabulary WER）

| 模型 | WER（自動辨識） |
|------|----------------|
| Gaddy & Klein 2020 | 68.0% |
| **本模型** | **42.2%** |
| 人工轉錄（平均）| 32.3%（36.1% / 28.5%）|

改善幅度：絕對 25.8%，相對 38%

### 消融實驗

| 移除項目 | WER | 相較完整模型 |
|----------|-----|-------------|
| 無（完整模型） | 42.2% | — |
| 換回手工特徵 | 45.2% | +3.0% |
| Transformer → LSTM | 46.0% | +3.8% |
| **移除音素輔助損失** | **51.7%** | **+9.5%** |

音素輔助損失是三項貢獻中影響最大的。

### 音素混淆分析（前五對）

| 音素對 | 混淆率 |
|--------|--------|
| dʒ / tʃ | 13.2% |
| v / f | 10.4% |
| p / b | 10.3% |
| m / b | 9.3% |
| k / g | 8.9% |

主要混淆模式：清濁音對（place、manner 正確但 voicing 錯）、鼻音與塞音混淆（軟顎距離電極較遠）。

## 8. 論文限制

- **單說話者**：全部實驗在一位說話者的 19 小時錄音上進行，跨說話者泛化未驗證
- **英語限定**：音素集（39 個英語音素）無法直接遷移至聲調語言
- **WER 仍高**：42.2% 自動 WER 距實用水準尚遠
- **Session 嵌入依賴**：仍需每次重新貼電極後錄製少量有聲語音建立 session 嵌入
- **語音合成而非文字**：輸出為音頻，非直接文字辨識（需外接 ASR 才能得到文字）

## 9. 與我的研究的關聯

| 面向 | 關聯說明 |
|------|---------|
| 音素輔助損失 | 本篇首次提出 sEMG 的音素輔助任務；我的注音輔助任務（聲母 + 韻母 + 聲調）直接延伸此概念，針對聲調語言設計多標籤輔助損失 |
| CNN + Transformer 架構 | 確立了 sEMG 的主幹架構；我的系統沿用此架構，以 CTC 解碼器取代 DTW+MFCC 回歸，直接輸出文字 |
| 消融數據引用 | 音素損失貢獻（+9.5% WER）可作為「為何設計輔助任務」的量化支撐 |
| Session 嵌入 | 電極位置補償的設計思路；我的系統如採用固定電極配置，此問題重要性較低 |
| 音素混淆模式 | 清濁音混淆（voicing）在中文聲調辨識中對應聲調混淆（tone），語音神經肌肉訊號的不確定性在不同語言中有類比結構 |

## 10. 五個核心問題

1. **問題**：open vocabulary sEMG 語音合成 WER 為何仍高？
   → 主因：特徵表示不足（手工）、LSTM 時序建模有限、訓練訊號稀疏

2. **方法**：為何用相對位置編碼而非絕對？
   → 語音任務具時間平移不變性，相對位置更能泛化到不同語速

3. **資料**：DTW 對齊會引入誤差嗎？
   → 論文未深入分析對齊誤差，但雙模式訓練（有聲同步）有助緩解

4. **結果**：音素輔助損失為何是最大貢獻（+9.5%）？
   → 資料量小（19 小時），音素標籤提供額外監督訊號，防止 Transformer 過擬合

5. **限制**：能直接輸出文字嗎？
   → 不行，輸出是音頻，需再接 ASR（DeepSpeech）才能得到文字；改用 CTC 解碼器可解決此問題（Xie 2025 的做法）
