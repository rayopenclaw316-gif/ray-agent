讓人在不發出聲音的情況下，把臉部肌電訊號 (sEMG) 直接轉換成中文文字（EMG → Text）。

## 背景與動機

**問題**：一般 ASR 需要聲音，某些場合無法發聲（喉癌術後、噪音環境、保密需求）。

**EMG 的優勢**：肌肉收縮訊號在不發聲時仍存在，可偵測「無聲說話」的肌肉動作。

**前人不足**：
- 幾乎只針對英文
- 多數用傳統 HMM/GMM 架構
- 唯一深度學習例外（Wadkins 2019）只有 20 個詞彙

## 資料集

### 電極配置

- **8 通道差分電極**貼於臉部肌肉
- **1 個參考電極**在左鎖骨
- 採樣率：**1000 Hz**（EMG）/ 44100 Hz（音訊）
- 設備：Neuracle Technology NSW308M Bipolar System

| 通道 | 對應肌肉 | 重要性 |
|------|---------|--------|
| Ch 1 | 下顎肌 (jaw) | 靜默/有聲差異不明顯 |
| Ch 2 | 口輪匝肌 (orbicularis oris) | Baseline 最重要 |
| Ch 4 | 下顎骨肌 (mandibular) | AuxCEMGR 最重要 |
| Ch 5, 6 | 靠近喉嚨 (larynx) | 靜默模式反而較弱 |

### 收集流程

1. 志願者：一位女性普通話母語者
2. 文本：NBA 報導句子，平均 10 字/句，封閉詞表 667 個唯一字元
3. 兩種模式：**靜默模式**（EMG + 文字）/ **有聲模式**（EMG + 音訊 + 文字）
4. 每句重錄 **5 次**（5 sessions），每次重新貼電極

### 資料集統計

| 集合 | 句數 | 靜默時長 | 有聲時長 |
|------|------|---------|---------|
| 訓練 | 1,062 | 5.13 h | 4.98 h |
| 驗證 | 63 | 0.31 h | 0.31 h |
| 測試 | 113 | 0.48 h | 0.50 h |
| **合計** | **1,238** | **5.93 h** | **5.80 h** |

### 訊號前處理

1. **帶通濾波器**：10–400 Hz Butterworth 4 階
2. **陷波濾波器**：50, 150, 250, 350 Hz（去除市電 50Hz 及諧波）
3. **特徵萃取**：MFSC（log Mel 頻譜係數），Hanning 窗，36 個 Mel 濾波器

## 模型架構

### Baseline

```
輸入 S = s₁...sₙ（MFSC 特徵序列）
  ↓
CNN × 2（kernel 3×3）→ 時序壓縮
  ↓
Transformer Encoder × 6（8 頭，256 維）→ 高階特徵 H = h₁...hₜ
  ↓
CTC Decoder（Linear + Softmax）
  ↓
輸出 Y = y₁...yₘ（中文字元序列）
```

**為什麼用 Transformer**：捕捉長距離依賴，比 RNN/LSTM 更強。  
**為什麼用 CTC**：不需要時間對齊（T >> M），小資料集易訓練。

### 輔助任務 1：拼音生成 (Pinyin Generation)

- Encoder 共享，額外接一個獨立 CTC Decoder 輸出拼音序列
- **目的**：中文同音異字問題（如「知/之/支」同為 zhī），先學拼音可細化特徵
- 損失：`拼音損失 = -log( 模型預測正確拼音的機率 )`

### 輔助任務 2：Session 分類（對抗訓練）

```
Encoder 輸出 H
  ↓
梯度反轉層 GRL（梯度乘以 -1）
  ↓
Session 分類器
```

- **目的**：強迫 Encoder 學不出「是第幾次錄製」→ H 變成 session-invariant
- **概念**：Domain Adversarial Training（可延伸至跨人泛化）
- 損失：`Session 損失 = log( 模型預測正確 session 編號的機率 )`

### 總訓練目標

```
總損失 = 文字辨識損失
       + 權重1 × 拼音生成損失
       + 權重2 × Session 分類損失
```

最佳超參數：**權重1 = 權重2 = 1.0**

## 資料增強（三種方法）

| 方法 | 做法 | Test CER 改善 |
|------|------|--------------|
| 頻譜消減 (Spectral Subtraction) | 去噪版本加入訓練，資料量 ×2 | ~7–10% |
| 有聲資料補充 (Audible Data) | 有聲 EMG 打折加入（權重 γ=0.8） | ~5–9% |
| Mixup | 兩筆資料加權混合（α=0.02） | ~5–7% |

## 實驗結果

### 主要結果

| 模型 | 設定 | Dev CER | Test CER |
|------|------|---------|---------|
| Baseline | 無增強 | 63.8% | 66.5% |
| Baseline | 完整增強 | 37.2% | 44.5% |
| **AuxCEMGR** | **完整增強** | **30.7%** | **38.0%** |
| Wadkins LSTM | 完整增強 | 58.3% | 66.8% |

### 關鍵發現

1. **拼音輔助任務最有效**：拼音損失權重 > 0.5 時，CER 低於 Baseline（無論 Session 損失權重為何）
2. **三種增強缺一不可**：單獨移除任一方法均導致明顯下降
3. **Transformer >> LSTM**：LSTM 甚至無法從有聲資料中獲益
4. **Ch 4 最重要**（下顎骨肌），Ch 5, 6（喉嚨）在靜默模式反而最弱
5. **電極數量**：6–7 個電極效果接近 8 個，可提升穿戴舒適度

### 分析結果

- **句子長度**：≥12 字時 CER 明顯上升
- **Session 穩定性**：AuxCEMGR (Final) 跨 session 最穩定
- **有聲/靜默切換**：加入有聲訓練資料後，模型辨識有聲 EMG 效果大幅提升

## 深入解說：CTC 數學推導

### CTC 在做什麼

Encoder 輸出特徵序列 H（長度 T），通過線性層 + Softmax，得到每個時間步的字元機率：

```
pi_t[c] = 在時間步 t，輸出字元 c 的機率（由模型預測）
```

### 整條路徑的機率

CTC 把「一段輸出序列」叫做一條**路徑 C**（包含空白符號 `-`）。  
一條路徑的機率 = 每個時間步機率的連乘：

```
P(路徑 C | H) = pi_1[c1] × pi_2[c2] × ... × pi_T[cT]
```

### 一個文字輸出 Y 的機率

同一個文字輸出 Y，可以對應**很多條不同的路徑**（因為空白符號可以放在不同位置）。  
把所有能解碼出 Y 的路徑機率加總，就是 Y 的機率：

```
P(Y | H) = P(路徑1) + P(路徑2) + P(路徑3) + ...
         （所有能解碼出 Y 的路徑）
```

### 訓練目標

希望模型對正確答案 Y_correct 的機率越高越好，所以最小化：

```
CTC 損失 = -log( P(Y_correct | H) )
```

log 讓連乘變成連加，數值更穩定。負號是因為我們要最小化損失，但最大化機率，方向相反所以加負號。

### 計算技巧：動態規劃

直接列出所有路徑是指數級複雜度（字元數^時間步數），無法計算。  
CTC 用**動態規劃（Forward Algorithm）**高效計算：

```
定義：
  alpha(t, s) = 前 t 個時間步，恰好對齊到第 s 個標籤的所有路徑機率加總

遞推公式：
  alpha(t, s) = ( alpha(t-1, s) + alpha(t-1, s-1) ) × pi_t[第s個標籤]

意思：
  - alpha(t-1, s)   → 上一步也在第 s 個標籤（停留）
  - alpha(t-1, s-1) → 上一步在第 s-1 個標籤（前進）
  兩種情況都能走到現在，所以相加
```

## 深入解說：Beam Search 解碼

推論時，貪心解碼（每步只取機率最大的字元）不一定找到整體最佳答案。

**Beam Search** 同時保留前 k 條最佳候選路徑（本論文 k=5）：

```
時間步 1：
  所有字元都試一遍，保留機率最高的前 5 個字元作為候選

時間步 2：
  每個候選接上所有可能的下一個字元（5 × 字元數 種組合）
  保留機率最高的前 5 條路徑

...

時間步 T：
  取 5 條候選中機率最高的那條，作為最終輸出
```

k 越大結果越好，但計算量越大。k=5 是效果與速度的折衷。

## 深入解說：對抗訓練與梯度反轉層（GRL）

### 問題：Session 噪音

每次重新貼電極，EMG 訊號稍微不同。若模型學到「session 1 的訊號長這樣」，會把 session 資訊混進特徵，干擾辨識。

**目標**：讓特徵 H 只保留語音資訊，對 session 資訊「視而不見」。

### 架構

```
         ┌──────────────────────────┐
輸入 X → │   Encoder（特徵提取器）   │ → H
         └──────────────────────────┘
                      │
         ┌────────────┴────────────┐
         ↓                         ↓（經過 GRL）
┌─────────────────┐    ┌───────────────────────┐
│  文字辨識頭     │    │  Session 分類頭        │
│  目標：降低     │    │  目標：猜對是第幾次錄製 │
│  文字辨識損失   │    │                       │
└─────────────────┘    └───────────────────────┘
```

### 梯度反轉層（GRL）的運作

**前向傳播**：什麼都不做，H 原封不動傳給 Session 分類頭。

```python
# 前向
output = input  # 不變
```

**反向傳播**：把梯度乘以 -1 再傳回 Encoder。

```python
# 反向
grad_input = -lambda × grad_output  # 負號！
```

### 對抗效果

```
Session 分類頭：努力學「分辨是第幾次錄製」
      ↓
GRL 讓梯度反轉：Encoder 被迫往「無法分辨 session」的方向更新
      ↓
收斂結果：Session 分類準確率 ≈ 20%（5 個 session 隨機猜），
          代表 H 已成功移除 session 資訊
```

用白話描述這個對抗賽局：

```
文字辨識頭：想讓 Encoder 學好語音特徵（降低文字損失）
Session 分類頭：想讓 Encoder 保留 session 資訊（降低分類損失）
GRL：讓 Encoder 同時也想升高 session 分類損失
→ 三方角力，最終 Encoder 只剩下 session 無關的語音特徵
```

### 為什麼不乾脆忽略 session？

如果只是「不輸入 session 標籤」，模型可能無意中學到 session 的差異特徵。  
GRL **主動懲罰**這種行為，強迫遺忘。

### 延伸到你的研究

```
把「Session 分類頭」換成「受試者分類頭」
→ Encoder 學到跨人不變的 EMG 特徵
→ 一個模型可以用在多個人身上（跨人泛化）
```

## 深入解說：Mixup

### 原始 Mixup（分類任務）

把兩筆資料的輸入和標籤加權混合，產生新訓練資料：

```python
mix_ratio = Beta(alpha=0.02, alpha=0.02)  # 抽一個 0~1 的混合比例

x_new = mix_ratio × x1 + (1 - mix_ratio) × x2   # 輸入混合
y_new = mix_ratio × y1 + (1 - mix_ratio) × y2   # 標籤混合（one-hot 向量）
```

**直覺**：讓模型學到更平滑的決策邊界，不要對訓練樣本過度自信。

### 為什麼 CTC 不能直接混合標籤？

分類任務的標籤是固定長度的向量，可以直接加權平均。  
CTC 的標籤是**不等長的文字序列**：

```
Y1 = "知道"     長度 2
Y2 = "三分球"   長度 3
→ 無法相加，沒有辦法算出 Y_mix 是什麼
```

### 作者的解法：混合損失而非標籤

不混合標籤，改為直接對損失做加權：

```python
mix_ratio = Beta(0.02, 0.02)
X_mix = mix_ratio × X1 + (1 - mix_ratio) × X2   # 只混合 EMG 輸入

loss1 = CTC損失(X_mix, Y1)   # 混合輸入對第一個答案的損失
loss2 = CTC損失(X_mix, Y2)   # 混合輸入對第二個答案的損失

最終損失 = mix_ratio × loss1 + (1 - mix_ratio) × loss2
```

**白話**：輸入有 70% 來自第一筆，就要求模型對第一個答案有 70% 的信心；對第二個答案有 30% 的信心。

### 為什麼 alpha=0.02 這麼小？

Beta(0.02, 0.02) 的分布是 U 型，幾乎所有抽到的值都接近 0 或 1：

```
大多數情況：mix_ratio ≈ 0.98 或 0.02
→ 混合後幾乎等於原始其中一筆資料
→ 混合效果溫和，不破壞 EMG 的時序結構
```

### 三種增強方法的互補關係

```
頻譜消減  → 解決「電極貼附不穩定造成的高頻噪音」
有聲資料  → 解決「靜默 EMG 資料量太少」（借助有聲模式補充）
Mixup     → 解決「特徵空間稀疏」（插值產生邊界樣本）

三種方法針對不同問題 → 合用比單用任何一種都好
```

## 模型完整訓練流程

```
一個 mini-batch 的訓練步驟：

1. 從 (X, Y_文字, Y_拼音, session編號) 抽一批資料

2. 以 50% 機率做 Mixup（混合兩筆資料的 EMG 輸入）

3. 以 50% 機率改用頻譜消減版本的 X

4. 前向傳播：
   X → CNN（2層）→ Transformer（6層）→ 特徵 H

5. 計算三個損失：
   文字損失    = CTC(H, Y_文字)
   拼音損失    = CTC(H_拼音分支, Y_拼音)
   Session損失 = CrossEntropy(GRL(H), session編號)

6. 加總：
   總損失 = 文字損失 + 1.0 × 拼音損失 + 1.0 × Session損失

7. 反向傳播（GRL 在此步把梯度取負號傳回 Encoder）

8. Adam 優化器更新參數（Noam warmup 學習率排程）
```
