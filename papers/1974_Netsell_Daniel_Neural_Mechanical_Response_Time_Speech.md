## 2. 一句話總結

量化正常成人發音時的「神經時間」（EMG 啟動前延遲）與「機械反應時間」（EMG 啟動到口腔氣壓完成），確立 EMG 訊號比聲音早約 60 ms 產生的生理基準。

---

## 3. 三個主要貢獻

| # | 貢獻 |
|---|------|
| 1 | 首次以反應時間範式量化語音生產的神經時間（~142 ms）與機械反應時間（~64 ms） |
| 2 | 證明 EMG 訊號比實際語音早 ~60 ms，為 sEMG-SSI 提供生理時間基礎 |
| 3 | 建立正常人的基準數據，供後續構音障礙（dysarthria）診斷對比使用 |

## 4. 背景與動機

**問題：** 語音是神經驅動→肌肉收縮→發音器官機械運動→聲音的串聯過程，但各環節的時間分佈從未被系統量化。

**目的：** 分離並測量正常成人發音時的兩個時間成分：
- **神經時間（Neural time, NT）**：刺激訊號消失 → EMG 啟動
- **機械反應時間（Mechanical response time, MRT）**：EMG 啟動 → 口腔氣壓上升（代表發音動作完成）

**應用動機：** 以正常人數據作為基準，用於解釋構音障礙患者的異常反應時間。

---

## 5. 資料集

**受試者：**
- 10 名神經學正常成年人（女 5 男 5，年齡 20–35 歲）
- 無語言、聽力、口腔顏面病史

**實驗設計：**
- 刺激：500 Hz, 85 dB 聲音（隨機持續 2.0–4.0 秒後關閉）
- 任務：聽到聲音停止後，盡快發出測試詞 [pap], [bap], [map]
- 每個詞各 15 次重複 × 2 顎部條件 = 90 筆/受試者

**兩種實驗條件：**
- 顎部固定（jaw stabilized）：咬合板固定下顎
- 顎部自由（jaw free）：正常狀態

**測量設備：**
- EMG：銀片表面電極（Allen et al., 1972），貼附上唇右側，測量口輪匝肌上部
- 氣壓：鼻內氣壓（P_n）與口腔內氣壓（P_o）感測器
- 麥克風：距唇 15 cm

**定義：**
```
NT  = 聲音停止 → EMG 啟動的間隔（msec）
MRT = EMG 啟動 → 口腔氣壓上升的間隔（msec）
RT  = NT + MRT（整體反應時間）
```

---

## 6. 模型架構

本研究無模型，為生理時間測量研究。時間成分分解如下：

```
[聲音刺激停止]
      |
      | ← 神經時間 NT (~142 ms)
      |    （感覺處理 + 皮層組織 + 運動指令傳導）
      v
[EMG 啟動：口輪匝肌收縮開始]
      |
      | ← 機械反應時間 MRT (~64 ms)
      |    （肌肉收縮 → 唇部閉合 → 口腔氣壓上升）
      v
[發音動作完成：聲音產生]

整體反應時間 RT = NT + MRT ≈ 206 ms
```

**關鍵比例：** 200 ms 的反應時間中，約 70% 在神經時間、30% 在機械反應時間。

## 8. 實驗結果

**主要數據（Table 1 摘要）：**

| 成分 | 平均值 (ms) | 說明 |
|------|------------|------|
| 神經時間 (NT) | ~142 | 刺激→EMG，跨顎部條件與音素無顯著差異 |
| 機械反應時間 (MRT) | ~64 | EMG→聲音，各條件約 44–86 ms |
| 整體反應時間 (RT) | ~206 | NT + MRT |

- 個體反應時間範圍：173–231 ms
- NT 範圍：121–163 ms；MRT 範圍：44–86 ms
- **顎部條件（固定 vs 自由）、音素類型（[p]/[b]/[m]）、性別均無顯著差異**（p < 0.01）

**關鍵發現：**
- MRT（EMG→聲音）約 60 ms，這是 sEMG-SSI 的生理基礎：EMG 天然地比聲音早 ~60 ms，攜帶即將發出什麼音的預測資訊
- 正常語音生產的神經時間與手指動作反應時間相近，口唇的反應速度和手指相當

---

## 9. 論文限制

- 只測量雙唇音（[p], [b], [m]），不代表所有語音的 EMG-聲音時間關係
- 受試者全為正常成人，無法直接應用於患者或無聲語音情境
- 使用的是「反應時間範式」（聽到訊號才發音），不等同於自然說話時的 EMG 提前量
- EMG 只測量一條肌肉（口輪匝肌），不能代表所有發音肌群的時間特性

## 10. 與我的研究的關聯

| 面向 | Netsell & Daniel (1974) | 我的研究方向 |
|------|------------------------|-------------|
| 目的 | 建立生理時間基準 | 以 EMG 辨識注音符號 |
| 應用 | 構音障礙診斷基準 | sEMG-SSI 特徵擷取 |
| 訊號 | 有聲語音 EMG | 無聲語音 EMG |
| 重要性 | 提供 ~60 ms 時間依據 | 說明為何 EMG 可預測語音 |

**對我的啟示：**
1. 這篇是你論文第一段的**核心生理基礎引用**，提供「60 ms」這個關鍵數字的原始出處
2. 需要注意：60 ms 是**機械反應時間（MRT）**，即 EMG 啟動到聲音產生的時間，不是整體反應時間（那是 ~200 ms）
3. 本文研究的是有聲語音，但無聲語音（silent speech）的 EMG 仍存在類似的預備活動，這個邏輯延伸需要在論文中說清楚

## 11. 五個核心問題

| 問題 | 答案 |
|------|------|
| 研究問題是什麼？ | 正常發音時，神經時間與機械反應時間各佔多少？ |
| 方法是什麼？ | 聽覺刺激→發音反應時間範式，同步測量 EMG 與口腔氣壓 |
| 資料如何取得？ | 10 名正常成人，3 個雙唇音 CVC 詞，90 筆/人 |
| 主要結果？ | NT ~142 ms，MRT ~64 ms，RT ~206 ms，各條件無顯著差異 |
| 主要限制？ | 只測雙唇音，反應時間範式不等同自然語音，EMG 只測一條肌肉 |
